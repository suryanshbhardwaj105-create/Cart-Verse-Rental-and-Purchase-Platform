# Cart-Verse — Rental and Purchase Platform

Cart-Verse is a web-based platform for browsing, renting, and purchasing products online. Built with HTML, CSS, and JavaScript on the frontend, with a Node.js + Express backend connected to MongoDB.

## Features
- User registration and login
- Browse products by category (men, women, kids)
- Shopping cart functionality
- Booking and payment pages

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (via Mongoose)
